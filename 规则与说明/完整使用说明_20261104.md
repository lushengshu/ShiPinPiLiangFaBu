# 抖音视频发布助手

这是一个运行在本机的轻量工具。它不保存抖音账号密码，也不尝试绕过验证码、风控或平台限制；它把视频、文案、话题、封面和发布状态整理在一个队列里，并通过独立的浏览器登录态逐条提交到抖音创作者中心。

## 启动

日常使用不需要复制地址到浏览器，也不需要手动输入 Python 命令：

1. 双击本目录中的 `视频发布工具.app`；如果系统不允许直接打开，可右键选择“打开”。
2. 也可以双击 `启动器/启动抖音发布工具.command`。它会复用已经运行的服务，或在后台启动服务，然后自动打开本地工具页面。
3. 页面地址是 `http://127.0.0.1:8765/`。只有在浏览器没有自动打开时，才需要手动访问这个地址。

启动器会等待 `/api/state` 真正可用后才报告成功，不会因为端口刚刚监听就误报“已打开”。如果启动失败，错误会保留在终端窗口，详细日志在 `.douyin_batch/server.log`。同一台电脑重复双击不会启动多个服务。

打开后先在发布队列的第 1 步选择“普通视频”或“全景视频”。选择全景时还要先选 `360°/180°` 的单目或双目格式；完成后点击“选择视频”按钮，菜单中可以选择“选择视频文件夹”扫描 A 盘、D 盘或其他磁盘上的目录，也可以选择“添加视频文件（可多选）”只挑选要加入队列的视频。新加入的视频会继承这次入口选择，并自动走对应的普通/全景上传方式；已有队列条目不会因切换入口而被静默改写。工具只读取文件，不会移动或复制原视频；支持 `mp4 / mov / m4v / avi / mkv / webm`。直接选择的外部磁盘文件会保存为绝对路径，以便发布器继续找到原文件。

如果需要从终端启动或指定端口，可以运行：

```bash
python3 launch_local_tool.py
DOUYIN_PORT=18765 python3 launch_local_tool.py
```

`launch_local_tool.py` 只负责启动本地页面，不会自动上传或发布视频。

如果视频放在其他目录，可以这样启动，工具不会复制或移动原文件：

```bash
DOUYIN_MEDIA_DIR="/你的/演唱会视频目录" python3 app.py
```

## 每条视频的配置

每条视频可以配置：发布类型（普通视频/全景视频）、全景格式、发布文案、话题、封面时间点、可见范围、是否允许下载、发布方式和备注。全景条目另有“自动匹配官方活动/话题”和“官方活动/话题匹配关键词（可选）”；关键词留空时会用当前文案/话题与抖音页面实际显示的官方活动卡片做保守匹配，找不到明确匹配就不选择。另有“授权 PICO 播放”开关，默认关闭，只有用户明确勾选才会在发布页尝试授权。封面时间支持秒数（如 `18`）或 `分:秒`（如 `00:18`）；留空时自动尝试选择视频中段画面。配置会自动保存到 `.douyin_batch/queue.json`。

### 全景视频发布

第 1 步选择“全景视频”后，必须先选择一种格式：`360°普通单目`、`360°立体双目`、`180°普通单目` 或 `180°立体双目`；未选格式前，视频选择入口会保持禁用，避免把普通视频误送进全景流程。已有条目仍可在卡片中单独修改，也可以先勾选多条视频，在队列工具栏的“批量覆盖队列发布类型”中显式应用全景类型和格式。工具不会仅凭文件名或 2:1 画幅自动把视频判定为全景；卡片上的本地预检只显示尺寸线索，最终以抖音全景编辑页的格式选择和预审为准。

全景自动发布会进入抖音独立的 `content/upload?default-tab=4` 上传页，不会回退到普通视频页。当前页面提示全景文件建议使用 `mp4 / mov`，大小不超过 16GB、时长不超过 10 分钟，推荐 4K（3840×1920）及以上；超过硬上限会在本地阻止启动，低于推荐分辨率只提示并交由抖音预审。DJI `.OSV` 是工程/原始素材，不能直接加入发布队列，请先在 DJI Studio 导出可上传的 MP4/MOV。全景格式确认后，工具还会等待可见上传进度达到完成并确认编辑器就绪，再进入封面步骤；全景封面弹窗会按封面时间自动选取帧缩略图后点击“完成”。进入发布设置时，会按队列文案/话题保守匹配页面可见的官方活动/话题卡片；如果页面把更多卡片折叠在“+N/更多”里，会先在官方活动区域安全展开再匹配。无明确匹配不选择，多项匹配或点击后无法回读会保留页面并自动暂停。PICO 开关只有在队列卡片明确勾选“授权 PICO 播放”时才会开启，恢复草稿时也会把开关回读为队列要求的状态。全景入口、格式控件或账号权限无法确认时，工具会保留 Chrome 页面、自动暂停并提示原因，不会改走普通发布或标记为已提交。

### 定时发布计划

页面中的“定时发布计划”现在位于“发布队列”内部，紧跟在选择/校验/匹配工具之后；填写的是抖音后台的预约时间，不是本地软件的等待时间。可以先设置首条时间，再选 `2 / 10 / 20 / 30 / 40 / 50 / 60 / 100` 分钟或自定义间隔，点击“生成定时计划”；之后仍可在每条卡片上改成“立即发布”、单独改具体时间或修改与下一条定时视频的间隔。修改单条间隔时，工具会提示并同步重算后续可编辑的定时视频；也可以混合立即发布和定时发布。

设置时间时会实时显示计划预览（首条、最后一条和总条数）；首条时间支持浏览器标准格式以及带秒/斜杠的写法，输入框为空时会自动填入“现在 + 10 分钟”的默认时间并继续，避免反复提示“请先选择”。修改时间、间隔或模式后会清除上一次的警告/成功提示，避免看到过期结果。

工具会逐条上传视频，并在抖音发布页明确选择“立即发布”或“定时发布”；定时日期和时间会动态填写并回读确认，确认失败时保留浏览器页面，不会误点成立即发布。工具会拒绝已经过去的预约时间；抖音账户可能有最早可预约时间限制，建议首条时间至少提前 10 分钟，最终以页面提示为准。最后一条的间隔可以留空；直接改某条绝对时间时以该时间为准，改间隔时才会按提示重算后续可编辑条目。

### 队列管理

队列上方的动线固定为：`01 选择发布类型 → 02 选择视频 → 03 校验视频 → 04 匹配发布内容 → 05 确认并发布`。入口类型会保存在当前浏览器的本地偏好中，刷新页面后仍会保留；它只决定之后新加入/新扫描文件的默认路线，不会覆盖已有条目的手工类型。当前队列包含普通和全景混合条目时，工具会提示“卡片设置优先”，发布器仍按每条视频自己的配置打开对应上传页。

- “选择视频”：点击后展开两个选项：
  - “选择视频文件夹”：扫描所选目录下的全部视频，并重建当前队列。
  - “添加视频文件（可多选）”：从本机一次选择一个或多个视频，追加到现有队列；重复文件会跳过。
- “清空队列”：位于“发布队列”标题旁，只清除 `.douyin_batch/queue.json` 中的队列记录，不删除源视频。
- 每条视频左侧可以勾选；勾选多条后点击“删除所选”，或在单条视频的操作区点击“删除”，只移除本地队列记录，不删除源视频。自动发布运行、暂停或终止处理中，选择、编辑、删除和清空按钮会锁定，避免破坏当前浏览器任务。
- 队列卡片按“视频身份与状态 → 当前文案摘要 → 主要操作 → 高级设置”的顺序呈现。编辑器默认折叠，点击“编辑文案与发布设置”展开；打开视频、复制文案、跳过和删除已放在“发布视频号”后方，轮询刷新会保留编辑器展开状态。

### 文案内容

当前主页面不展示旧版“视频内容识别/识别候选”入口；文案通过直接编辑、一键生成或导入模板维护，发布队列只保留选择、校验、编辑和发布相关操作。

### 文案编辑与导入

文案框和话题框可以直接修改；输入过程中页面的状态轮询不会重建正在操作的输入控件，因此焦点、光标和中文输入法不会被打断。输入停顿或离开输入框后会自动保存到 `.douyin_batch/queue.json`；保存失败时草稿仍留在当前页面，可重试。普通/全景、可见范围和定时等下拉框在打开或完成选择前也不会被轮询重绘打断；筛选下拉会在选择后立即刷新。

### 一键生成文案

队列第 4 步“匹配发布内容”里新增了“一键生成文案”。它按文件名里的歌名匹配本地文案库 `文案/song_copy_library.json`，为每条视频写入标题、描述和话题；不抽帧、不联网，通常一两秒完成。

- 勾选视频时只处理勾选项；没有勾选时处理全部未跳过、未提交的视频。
- 已有手写文案默认保留；勾选“覆盖手写”后会覆盖标题/描述/话题，并在写入前把队列备份为 `.douyin_batch/queue.before_copy_日期_时间.json`。
- 文案库没有匹配到的歌名会列在结果里，不会被猜配；需要支持新歌时编辑 `文案/song_copy_library.json`，保存后下一次点击自动生效，不需要重启服务。
- 生成只修改本地队列的 `work_title`、`caption` 和 `hashtags`，不改发布状态、不启动浏览器、不上传、不发布。
- 当前 27 首演唱会文案、识别依据和可直接导入的 Excel 模板在 `文案/` 目录；`文案/build_文案表_20261104.py` 会从同一份文案库重新生成表格。

队列工具栏和每条视频卡片都有“导入文案”入口。导入只修改文案/话题，不上传、不发布，也不会删除源视频：

自定义封面图片可以点击“导入自定义封面”批量加入。匹配以**歌曲名**为主：先去掉文件名里的日期、`横版/竖版`、`4比3/3比4`、`封面/真人实拍/合成/优化`等装饰词，再用歌曲名比对；`01_`、`02_` 这类设计批次序号不会要求与视频名里的编号一致，例如 `01_不朽_横版_4比3_20261031.png` 可以匹配 `2不朽.mp4`，`02_黑白艺术家_横版_20261103.png` 可以匹配 `4黑白艺术家.mp4`。如果文件名明确写了 `视频10`/`video 10`，该编号视为视频身份，与视频编号不一致时不会匹配；同名但版本号不同的候选分数接近时会保留为待确认，避免错配。`1开场封面.jpg` 仍可匹配 `1开场.mp4`，`3比4封面.png` 仍可匹配 `3比4.mp4`。横版和竖版会分别保存，例如 `歌曲_横版_4比3.jpg` 与 `歌曲_竖版_3比4.jpg` 会同时写入同一视频的两套封面；发布器进入抖音横版/竖版封面步骤时分别上传对应图片。每次导入都是增量合并：同一视频、同一版本再次匹配会替换旧文件，新匹配到的版本会新增，本轮没有上传的旧横版/竖版不会被清除；页面会明确显示本轮“替换 / 新增 / 待确认”的数量。未设置自定义封面时，继续按“封面时间（秒）”在视频中定位封面。每条视频的编辑设置里可以清除已匹配的自定义封面。

- `txt` / `md`：文件正文作为一条文案。先勾选一条视频，或在对应视频卡片上点击“导入文案”；勾选多条时会将同一正文应用到全部勾选项，并在覆盖前提示确认。
- `JSON`：可以是单个对象、对象数组，或 `{ "items": [...] }` / `{ "videos": [...] }` 等列表。每行可填写 `caption`（也支持 `text`、`description`、`文案`）、`hashtags`（也支持 `tags`、`topics`、`话题`），并用 `id`、`name` 或 `path` 指定目标。
- `CSV`：第一行是字段名，后续每行一条记录；字段名同 JSON。建议使用 `id,name,path,caption,hashtags`，路径或文件名会按规范化后的完整路径/文件名匹配。
- `XLSX`：点击“下载模板”可导出当前队列的文件名、标题、文案和话题；修改数据页后导入。填写说明单独放在说明页，旧模板末尾的说明也会自动忽略。标题会单独填写到抖音标题栏，描述只包含文案与话题。

没有勾选视频时，JSON/CSV 必须带有 `id`、`name` 或 `path` 才能匹配。提供 ID 或完整路径时优先严格匹配该字段；文件名重名或多条记录指向同一视频时不猜选，可单独选择目标视频或修正导入文件。确认后只写入匹配成功的记录，其余可导出排查 Excel，包含具体失败原因。勾选多条视频后，只有没有身份字段的记录才按队列中的勾选顺序应用；带有错误文件名的记录不会顺序写入其他视频，超出目标数量的记录也会保留在未匹配结果中。导入会明确提示覆盖范围，原始导入文件始终保留在本机。

## 当前的发布流程

1. 在发布队列第 1 步选择普通视频或全景视频；全景视频先选 360/180 的单目或双目格式。
2. 在第 2 步选择视频文件夹或添加一个/多个视频文件；新素材会继承入口类型并进入对应上传方式。
3. 完成视频校验、文案/话题/封面和定时设置。
4. 如需先手动打开后台，点击顶部的“打开普通上传页”或“打开全景上传页”；本地工具会保留在原标签页。
5. 点击红色的“开始发布”按钮即可开始；发布过程中同一个按钮会自动变为“暂停发布”，暂停后变为“继续发布”。
6. 工具会启动一个独立的 Chrome 配置目录。第一次运行时，在这个窗口完成抖音创作者中心登录；工具不会读取或保存密码。登录完成后，发布器会按每条视频自己的普通/全景类型进入对应入口，填写文案、自动处理封面弹窗，并按每条配置选择抖音的“立即发布”或“定时发布”；全景视频还会选择并回读四种全景格式。它会等待右侧上传进度真正结束，不会因为编辑页提前出现就进入下一条。
7. 当前抖音版本的封面流程可能包含“设置横封面获得更多流量”二级提示、横/竖封面时间轴和“保存/完成”按钮；新版抽帧弹窗不会默认选中帧，工具会自动选择与封面时间最接近的缩略图，再确认“完成”已启用。遇到验证码、声明或其他未知必填项时，会保留当前 Chrome 页面，不会擅自关闭，队列会标记为需要处理。
8. “发布”点击成功后只确认**提交回执**：立即发布条目直接显示为已发布/审核中，定时条目显示为已预约。不会等待抖音审核结果，也不会等作品卡片在内容管理列表完全加载；只要看到跳转回内容管理或新的提交成功提示，就继续下一条。审核结果可以在后续回传后单独更新，不阻塞队列。

### 发布链路校验（2026-11-04 修复）

- **发布按钮**：只认底部精确文本“发布”的主按钮，排除左侧导航“发布视频”；不会再把导航当成发布而离开编辑页。
- **标题/描述**：兼容新版 Slate 描述框、零宽字符和 `#话题` chip；回读不一致时会改用键盘写入重试，仍不一致则保留页面并暂停，绝不带着缺标题/缺描述发布。
- **话题**：描述框只填正文，话题不再拼成 `#话题` 普通文字；每个话题另起一行输入 `#话题`，从抖音话题面板选择精确候选，生成真正的话题 chip。找不到精确候选会保留页面并暂停，不会把普通文字当成话题发布。
- **自定义封面**：通过“上传封面”触发的原生文件选择器上传，不再误用“付费内容封面”的隐藏 input；横版和竖版会分别在“设置横封面/设置竖封面”标签上传各自的原图，不会再只传横版让平台裁切出竖版。上传后仍要求封面弹窗关闭且不显示“横/竖双封面缺失”。
- **上传完成**：不再把旧“上传成功”提示或任意 textarea 当作当前视频已就绪；要求标题/描述编辑器、发布按钮、当前文件名/上传进度同时满足，旧提示不参与判断。
- **成功判定**：必须在内容管理卡片中按作品标题/文案并带当天日期或审核/预约状态确认，或出现点击后新增且带本条标题的成功提示；旧作品、旧提示和页面导航文字都不算成功。
- **结果不明**：点击发布后若未确认结果，只保留页面继续观察，不会再次自动点击“发布”，避免重复提交。
- **日志**：发布器逐行 flush 到 `.douyin_batch/publisher.log`；服务端启动发布器时设置 `PYTHONUNBUFFERED=1`，运行中可直接查看进度与失败原因。

自动发布过程中点击同一个控制按钮即可暂停。暂停采用安全检查点：不会关闭 Chrome、不会清空当前页面，也不会跳到下一条；当前上传进度可以自然完成，但工具会停在当前步骤。页面显示“已暂停”后，同一个按钮会变成“继续发布”，点击即可恢复。暂停不会顺延已经写入抖音后台的预约时间；如果暂停时间较长，继续前请检查卡片中的预约时间。若发布器因异常退出，页面会显示“自动暂停/需要人工处理”，此时的“继续发布”会按队列中的 `publishing` 状态重新拉起并尝试恢复当前草稿。

如果不是你点击暂停，而是定时设置、封面/权限校验、页面异常或发布进程中断导致任务停住，工具会标记为“自动暂停”，并在本地页面弹出一次提醒，显示暂停原因和当前视频。提醒可以关闭；关闭只隐藏通知，不会自动继续发布。请先按提示检查保留的 Chrome 页面，处理完成后再点击“继续发布”。同一暂停事件不会在轮询中反复弹出；你手动点击“暂停发布”或“终止当前任务”不会触发这类异常提醒。

如果需要立即放弃本轮自动操作，直接点击“终止当前任务”即可，不再弹二次确认。这个按钮会和“继续发布”并列显示；即使自动暂停后发布器已经退出，只要页面还保留当前视频，也可以直接终止。工具会强制结束本项目的发布进程，保留 Chrome、抖音当前草稿/提示和本地队列，不删除源视频；页面显示任务已终止后，才可以点击“清空队列”。终止不会把当前条目误记为已发布，当前条目会保留为“发布中”以便检查或稍后继续。服务端会先校验进程确实属于本项目，再按强度递进停止，因此旧版本已启动的任务也可以使用同一个终止按钮。

如果当前队列没有待发布视频，“开始发布”会保持禁用，并明确提示先选择新文件夹或添加视频；这样不会误把已提交视频重复发布。

首次建议只保留 1 条待发布视频进行试跑，确认抖音页面的上传控件、封面要求和发布按钮匹配后，再批量处理。

队列和文案保存在 `.douyin_batch/queue.json`，下次启动会继续保留。

## 从抖音工作台桥接发布视频号

## 平台入口与独立视频号页

打开 `http://127.0.0.1:8765/` 后先选择“抖音发布”或“视频号发布”，点击后在新窗口打开对应工作台。抖音进入原有工作台；视频号进入独立的 `http://127.0.0.1:8786/` 页面，使用 `.channels_batch/queue.json` 和 `.channels_browser_profile`，不会读写抖音队列。

视频号页每条视频可配置：短标题、描述、话题、3:4 竖封面、4:3 横封面、合集和定时发布；选择视频使用一个下拉按钮，可导入整个文件夹或一次多选单个/多个视频；封面支持“导入封面”批量选择图片，使用与抖音一致的智能文件名匹配，也可在卡片上手动指定。读取合集时会用仓库内的微型测试视频打开表单，不会发表该测试视频。

抖音主页面现在提供“发布视频号”按钮，直接复用当前抖音队列中的视频路径、作品标题、文案和话题。勾选视频后点击，使用勾选项；没有勾选时，使用队列中可发布的普通视频。全景视频会自动跳过并显示“视频号不支持全景视频”。

视频号发布器以共享队列模式运行，直接回写同一条队列记录的 `platforms.channels.status/note/updated_at`，不会改抖音自己的 `status`。抖音和视频号的发布状态独立显示在卡片平台徽章上。视频号任务运行时，队列编辑会暂时锁定，避免文案保存和发布器同时改写同一条记录。

视频号任务运行中，页面会显示“暂停视频号”和“终止视频号”。暂停在当前视频完成后生效，浏览器页面保持打开；继续后从下一条接着跑。终止会立即关闭发布进程和专用 Chrome，当前条目标记为失败，可重新发布。视频号短标题会先清洗中文逗号等不支持的字符，并自动选择必填的“视频标注”。

视频号封面在视频上传完成后自动设置：个人主页 3:4 使用该条视频的竖版封面；分享卡片 4:3 使用同一条视频的横版封面。设置 4:3 时如果弹出“使用此素材作为封面?”，会自动选择“直接编辑”再上传横版，避免用 3:4 裁切；封面文件按队列中同一个视频的 `cover_image_portrait` / `cover_image_landscape` 匹配，不会串用其他视频。

视频号发布严格按以下顺序执行：1 上传视频 → 2 上传完成后设置 3:4/4:3 封面 → 3 填写标题 → 4 填写描述 → 5 选择视频标注 → 6 点击发表。封面步骤失败会保留页面并暂停，不会在没有封面的情况下继续发表。

视频号短标题超过字数限制（页面提示或输入框截断）时，保留歌名作为短标题，把日期、地点等后半段内容移到描述最前端，再接原描述和话题。例如“好想爱这个世界啊，2026.10.06南京”会变成短标题“好想爱这个世界啊”，描述以“2026.10.06南京”开头。
