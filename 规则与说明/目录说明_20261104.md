# 工作目录说明（2026-11-04）

## 日常可见分类

| 位置 | 放什么 |
|---|---|
| `启动器/` | 可双击的抖音、视频号命令启动入口。主应用 `视频发布工具.app` 保留在根目录。 |
| `文案/` | 文案库、成品表格、识别依据、截图和生成脚本。 |
| `封面素材/` | 封面成品、制作过程、素材迁移及相关脚本。 |
| `技能/` | 可复用的 AI 工作流、技能包、复盘与校验文件。 |
| `规则与说明/` | 使用说明、目录规则、设计规范。 |
| `tools/` | 主程序正在调用的媒体分析工具，以及历史工具测试归档。 |
| `项目存档/` | 历史开发产物、浏览器配置备份和可回溯记录。 |

## 不移动的运行区

根目录的 `app.py`、`browser_publisher.py`、`channels_app.py`、`channels_publisher.py`、`launch_local_tool.py`、`static/`、`.venv/` 及隐藏队列 / 浏览器配置目录属于运行区。发布服务运行期间不要移动、重命名或删除它们。

## 清理原则

只删除可重新生成且已核对无引用的缓存文件；不根据文件名猜测“无效”，不删除封面、文案、账号登录态、队列或历史项目原件。
