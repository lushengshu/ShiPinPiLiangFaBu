# 视频发布工具

更新日期：2026-11-05

## 直接使用

- 主入口：双击 视频发布工具.app，启动抖音视频发布工具。
- 视频号入口：`启动器/启动视频号工具.command`。
- 启动后 App 会常驻 Dock 托管本地服务；退出 App 会同时停止服务，使用期间请不要强制退出。
- 如果页面提示「无法连接本地服务」或 `Failed to fetch`，说明服务已经退出：重新双击 App，再刷新页面即可。
- 文案、封面和技能均已按用途归类；详细说明见 规则与说明／完整使用说明_20261104.md。

## 目录导航

| 目录 | 内容 |
|---|---|
| 启动器 | 抖音、视频号的可双击命令启动入口 |
| 文案 | 共享文案库、成品表格、识别依据与截图 |
| 封面素材 | 封面制作过程、生成试样、汇总与素材处理记录 |
| 技能 | 可交付给其他 AI 的封面工作流与历史技能包 |
| 规则与说明 | 使用说明、目录规则和设计规范 |
| tools | 正在被主程序调用的媒体分析工具及工具测试归档 |
| 项目存档 | 历史报告、旧启动器和已归档开发产物 |
| tests | 自动化测试代码 |

根目录的 app.py、browser_publisher.py、channels_app.py、channels_publisher.py、static 和隐藏运行数据是正在使用的核心程序，当前服务运行期间不移动。
